Privacy Policy - Email Triage Tool

Last updated: 22 October 2026

Email Triage Tool is a personal tool written and used by one person (William Wilson) on his own computer. It is not offered to the public.

What it accesses

With the owner's permission, it reads and organises email in the owner's own Google (Gmail) accounts, using Google's sign-in (OAuth).

What it does with the data

  1. Email data is processed only on the owner's own computer.
  2. It is not sold, shared with anyone, or used for advertising.
  3. It is not shown to any other person.

Google user data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.
